## 下午补充记录（约 10:30-11:00）

### 聊天列表左滑功能修复（MobileChat.vue）
**问题**：左滑操作按钮（置顶/删除）一直默认显示，没有左滑也会出现。

**尝试方案**：
1. CSS opacity: 0/1 控制 → 无效
2. CSS display: none/flex 控制 → 无效
3. Vue v-show 指令 → 无效
4. Vue v-if 严格条件 → 成功！

**最终方案**：
```vue
<div class="chat-item-actions" v-if="!!swipedId && swipedId === g.id && !!g.id">
```
使用 v-if 双重保险，确保 swipedId 有值、g.id 有值、且两者相等时按钮才渲染到 DOM。

**修复 touchend 后按钮消失问题**：
- 根本原因：touchend 后会触发 click 事件，click 处理器直接关闭按钮
- 解决方案：加 swipeMoved 标志区分滑动和点击，滑动后忽略 click

**其他修改**：
- 移除操作按钮的 emoji 图标，只保留文字（置顶/取消置顶、删除）
