# 2026-04-17 工作记录

## 时间

## 目标
- 消息列表只显示通讯录会话（自己发起的永远显示）
- 支持删除会话（企业微信风格）
- 支持置顶/取消置顶会话

## 后端改动 (functions/adminapi/[[path]].js)

### handleChatGroups 过滤逻辑修改
- 自己发起的群聊：始终显示（不过滤）
- 他人发起的群聊：所有成员必须在通讯录（员工+Agent）内才显示

### handleCreateGroup 成员校验
- 新增 `getContactIds()` 获取通讯录成员列表（员工ID + Agent虚拟ID）
- 创建群聊时校验所有成员必须在通讯录，否则拒绝

### 新增 API
- `POST /adminapi/chat/groups/:id/pin` — 置顶/取消置顶（`is_pinned` 字段）
- `DELETE /adminapi/chat/groups/:id` — 删除会话（同时删群聊+成员+消息+未读记录）
- `GET /adminapi/chat/contacts` — 获取通讯录成员列表（员工+Agent），用于发起会话

### handleGetGroup 响应新增 `is_pinned` 字段

### handleChatGroups 排序
- 优先按 `is_pinned` 降序（置顶在前）
- 其次按 `last_message_at` 降序（最新在前）

## 前端改动 (MobileChat.vue)

### 消息列表排序（displayedGroups）

### 菜单样式

### loadGroups 映射新增 `is_pinned`、`last_message_at` 字段
