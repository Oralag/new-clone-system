## 文件结构
- `01-世界观与角色设定.md`：角色设定、世界观、人格、生存规则、第一天、日记本
- `02-交易机制与财务规则.md`：股票分析、信用、预算、分红、赔付、净值、保险箱
- `03-城市与生态园区.md`：城市建造、Agent 园区、机构解锁、跨机构任务
- `04-交互流程与UI设计.md`：任务板、对话、视觉规范、MVP 页面、情绪面板、成长时间线
- `05-系统架构与开发落地.md`：路由/Store/API、权限边界、Prompt 分层、Worker、开发注意事项
- `06-开放问题与编码顺序.md`：剩余待定问题 + 推荐编码顺序

## 推荐编码顺序
1. **交易闭环**：指令生成 → 采纳/跳过 → 手动录入结果 → 信用/预算/净值变化
2. **亚当主面板**：状态卡、最新指令、今日动态、信用摘要
3. **对话与任务板**：让亚当先“能说、能记、能回看”
4. **城市观测窗**：先占位，再替换成真实等轴测资源
5. **生态园区机构**：投资局 / 研究院 / 情报站 / 保险箱逐步接入
6. **自主性与定时任务**：主动消息、人格更新、市场扫描

- 真正开工时，再从分类文件继续拆成：`data-model`、`api-contract`、`ui-spec`、`milestone-plan`
