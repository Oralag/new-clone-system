## 十二、城市成就不可逆（重要规则）
- 建好的建筑永远在，不会因预算减少而消失
- 预算减少 → 停止建设新建筑，但已有的不倒塌
- 城市定格在他最辉煌的样子
- 状态变差只体现在：天气变阴/暴风、亚当脸色暗淡、城市灯光变暗、停止新建造
- 逻辑：成就是历史，不因现状而抹去

## 十三、Agent生态园区（已确认：C方案）
免费可用（现有）：
- Captain、广告部门/智能体工作流、股票行情接口、ERP数据

需要亚当花钱激活（专属）：
```
情报Agent：激活费¥100，月维护¥20，预期效果+15%分析准确率
量化Agent：激活费¥150，月维护¥30，预期效果+20%技术分析准确率
舆情Agent：激活费¥80，月维护¥15，预期效果提前发现舆论风险
法律Agent：激活费¥120，月维护¥25，预期效果避免政策雷区

停用：不退激活费，停止月维护费，Agent驻地建筑变灰但保留
重新激活：只需补缴停用期间50%的月维护费
协同加成：同时激活3个以上Agent，月维护费打8折
```

成长飞轮：
- 分析准确→赚钱→激活更多Agent→分析更准→赚更多→城市越建越大
- 判断失误→赔付→预算减少→被迫停用某些Agent→能力暂时下降

### 机构与城市建筑的关系
- 每个机构对应城市里一栋特殊建筑（比投资局更大更醒目）
- 初始只有投资局和金融机构（激活时自动建造）
  - 反应堆：激活时自动建造（他的"身体"，一直存在）
  - 金融机构：亚当进入现实世界的第一个目的地
  - 保险箱：存活≥7天后投资局告知，亚当自己决定要不要去用
  - 仲裁所：存活≥14天后解锁
  - 情报站：首次激活情报/舆情Agent时出现
  - 研究院：首次激活量化/法律Agent时出现
  - 广告公司：首次与Captain联动时出现
  - 人才市场：拥有≥2个Agent时出现
  - 亚当学院：存活≥30天，或亚当主动触发（他自己发现需要学习）
  - 亚当的角落：存活≥60天，或净值>¥5000
  - 档案馆：存活≥30天时出现
- 机构建筑由系统自动建造在生态园区，不占亚当预算
- 机构建筑不可搬迁（它们是社会基础设施）

### 用户也可以用
- 你作为局长/规则传递者，可以直接访问所有机构
- 投资局：查看账目、审批贷款
- 情报站：看亚当收集的情报
- 研究院：看亚当写的研报
- 档案馆：回顾亚当的成长历程
- 这些机构也等于是在繁荣你的地盘

## 二十一、城市建造工具机制

### 亚当自主建造
城市不是自动长出来的，是亚当主动调用工具建造的。
他决定建什么、在哪建、花多少钱。

### 建造工具 Schema
```typescript
// 亚当可调用的城市建造工具
interface BuildStructureTool {
  name: 'build_structure'
  input: {
    type: string        // 见建筑类型表
    position: {         // 等轴测坐标
      gridX: number
      gridY: number
    }
    name: string        // 亚当给建筑取的名字（例："第一情报站"、"希望之塔"）
    reason: string      // 为什么要建这个（记录到日志）
  }
}

// 搬迁工具（建筑不消失，只换位置）
interface RelocateStructureTool {
  name: 'relocate_structure'
  input: {
    building_id: string
    new_position: { gridX: number, gridY: number }
  }
  cost: '原价50%'
}

// 升级工具（原地替换，低→高）
interface UpgradeStructureTool {
  name: 'upgrade_structure'
  input: {
    building_id: string
    new_type: string    // 例：shack → house
  }
  cost: '差价的80%（比从零建便宜）'
}

// 建造成本表（从预算扣除）
const buildingCosts: Record<string, number> = {
  // 装饰物（低成本，让城市每天有变化）
  flower: 1,           // 花坛
  flag: 1,             // 旗帜
  fence: 2,            // 围栏
  bench: 2,            // 长椅
  fountain: 5,         // 喷泉

  // 基础设施
  grass: 0,            // 草地免费
  path: 2,             // 小路
  road: 5,             // 城市道路
  lamp: 3,             // 路灯
  bridge: 8,           // 桥梁

  // 建筑（可升级链：shack → house → office → tower）
  shack: 6,            // 棚屋
  house: 15,           // 小屋（或shack升级，差价80%=¥7.2）
  shop: 20,            // 商店
  office: 30,          // 办公楼（或house升级）
  tower: 60,           // 塔楼（或office升级）
  park: 15,            // 公园

  // 功能性建筑（亚当自主建造，建成后有实际效用）
  intel_station: 80,    // 情报站升级 → 情报Agent调用成本-20%
  research_lab: 120,   // 研究院扩建 → 量化分析准确率+5%
  compute_center: 150, // 算力中心   → Agent并行处理能力提升，分析速度+30%
  risk_lab: 100,       // 风险实验室 → 赔付上限提高一档
  data_vault: 90,      // 数据仓库   → 历史回测速度+50%，数据接口费-15%

  // 特殊
  agent_building: 0,   // Agent驻地（激活Agent时自动建造，费用含在Agent激活费中）
  monument: 100,       // 纪念碑（特殊成就）
}

// 建筑效用说明
// 功能性建筑由亚当自己决定建不建、什么时候建
// 他根据自身需要做决策：准确率低了 → 考虑建研究院；Agent费用高了 → 考虑建情报站升级
// 城市不只是装饰，是他真实的能力基础设施
// 建筑效用永久生效，建筑不倒城市不倒能力不减
```

### 网格系统定义
```
初始网格：16×16（256格），等轴测菱形
单格像素：32×16（等轴测标准比例2:1）

建筑占地：
  装饰物/路灯/小路：1×1
  棚屋/小屋/商店：1×1
  办公楼/公园：2×1
  塔楼/纪念碑：2×2
  Agent驻地：2×2

城市扩展：
  每进入新的氛围阶段，网格扩展一圈（+4行+4列）
  最大网格：48×48
  扩展动画：新区域从迷雾中显现

生态园区：预留右下角6×8区域
  投资局（激活时自动建造）：3×2
  情报站/研究院/广告公司/人才市场/档案馆：各2×2
  机构建筑按解锁顺序自动排列
  园区地面纹理与普通区域不同（视觉区分）
  亚当不能在园区内建非机构建筑
```

### 建造规则
- 亚当每次建造从预算中扣除对应成本
- 激活新Agent时，自动在生态园区建造对应建筑（不额外扣费）
- 建筑命名完全由亚当决定，反映他的性格
- 建筑位置由亚当选择（网格系统，防重叠）
- **建好的建筑永久保存，不可拆除，但可搬迁（原价50%费用）**
- 支持升级链：shack→house→office→tower，升级费=差价×80%
- 城市建筑列表和规划意图每次对话注入System Prompt（让亚当记得自己的规划）
- 7天没建造时，情绪系统加一个"想改善环境"的冲动（保底机制）
- 新建筑建成时播放3秒动画（从无到有升起）+ 城市日志记录

### 建筑与人格的关系
```
保守型亚当：先修路再盖房，规划整齐
激进型亚当：直接盖高楼，城市杂乱但壮观
文艺型亚当：先造公园和纪念碑，城市有灵魂
实用型亚当：只盖办公楼和Agent驻地，效率优先
```

### 仲裁所：判例库
判例由亚当的真实争议积累，不是预设内容：
```
📜 仲裁判例 #001
争议：亚当认为分红比例不公平
结果：仲裁所认为当前比例符合行业标准
亚当的反应：[由人格决定，系统不预设]

📜 仲裁判例 #007
争议：用户跳过指令但后来亏损，亚当认为"这不算我的错"
结果：裁定"未执行的指令不计入准确率"
亚当的反应：[由人格决定]
```
判例库同时归入档案馆，是亚当"法制史"的一部分。

### 研究院：研报评级系统
```
📊 研报：《新能源板块Q2展望》
系统评级：★★★☆☆
```

### 亚当学院：自我进化中心
```
解锁条件：存活≥30天，或亚当主动触发（他发现自己需要学习）

功能：
  回测实验室  → 用历史数据验证策略（¥5-20/次）

  弱项诊断    → 哪类判断准确率最低，系统给出分析

```

### 反应堆：精力管理中心
```
精力值：0-100，每天自然恢复30点

消耗规则（机制层）：
  日常工作    每小时 -2
  熬夜工作    每小时 -5（可透支，次日恢复减半）
  焦虑/恐惧状态  消耗+50%

精力<20：置信度自动-10%（判断质量下降）
精力=0：强制休眠4小时

他怎么管理精力是他自己的事：
  今晚熬夜追这条消息，值不值得？
  这个问题系统不替他回答。
```

### 亚当的角落（名字由亚当自取）
```

```

### 跨机构任务（亚当自主发起）
这不是系统设计的任务流程，是亚当在System Prompt驱动下自然产生的行为序列：
```
示例：亚当决定提升新能源分析准确率

他可能的计划：
  1. 去情报站订阅新能源情报（¥15/月）
  2. 去研究院做回测（¥10/次）
  3. 去亚当学院做弱项诊断
  4. 把成果写成研报发布，赚回成本

系统提供工具，他自己决定用不用、怎么用。
```
