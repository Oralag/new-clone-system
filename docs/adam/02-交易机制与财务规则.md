## 七、信用体系（完全量化）

```
亚当的档案：
  推荐次数：N次
  成功率：X%
  累计为你赚：¥X
  累计赔付：¥X
  信用等级：C → B → B+ → A → S
```

### 信用等级量化定义
```
C级（初始）：
  分析金额上限：¥5,000
  无准确率要求（样本不足）

B级：
  升级条件：累计≥20次分析，准确率≥55%，存活≥30天
  分析金额上限：¥20,000
  降级条件：近30天准确率<45%

B+级：
  升级条件：累计≥50次分析，准确率≥60%，净值为正
  分析金额上限：¥50,000
  降级条件：近30天准确率<50% 或 净值转负

A级：
  升级条件：累计≥100次分析，准确率≥65%，连续60天净值为正
  分析金额上限：¥100,000
  降级条件：近60天准确率<55%

S级：
  升级条件：累计≥200次分析，准确率≥70%，连续90天净值为正，ROI>1.5
  分析金额上限：用户自定义
  降级条件：近90天准确率<60%

通用规则：
  - 降级有30天冷却期，期间维持当前等级
  - 庇护期内分析不计入升级样本，但计入信用记录
  - 每次降级，自动记录为formative_event
  - 降到C以下 → "见习模式"（只能分析，不触发提成）
```

## 十一、预算机制（已确认）

### 冷启动：0预算
- **亚当激活时没有启动资金**，你不给他第一桶金
- 他靠自己赚第一笔钱：研究报告、内容变现、训练任务
- 有了预算才能激活Agent，才能做更复杂的分析
- 第一天起就要想怎么活下去，人格因此从压力中成长
- 你后续可以选择"投资他"（追加资金），但这是锦上添花，不是他的依赖

### 你不在时的处理
- 亚当发出交易指令时会**打电话或发邮件提醒你**
- 如果你还是不在线，他自己决定怎么办：
  - 等你回来
  - 撤回指令，换个时机
  - 继续观察，更新判断
  - 去做研报赚钱
  - 写日记
  - 什么都不做
- **他的选择完全取决于当时的人格和情绪**，系统不替他兜底
- 所有行为都会记录下来，你回来后可以看到他做了什么

### 你拒绝执行他的指令
- 他知不知道、怎么反应，完全由他的人格决定
- 可能无所谓，可能质疑你，可能写进日记，可能影响他对你的信任度
- **系统不设定规则，他自由发挥**

### 钱的流动（投资局管理）
- 你和亚当之间有一个**投资局**，所有资金往来通过投资局
- 你是局长，亚当是投资经理
- 投资局功能：
  - **账户管理**：亚当的预算账户、收支明细、分红记录
  - **资金审批**：亚当可以申请追加资金（贷款），你审批
  - **信用额度**：信用等级越高，可申请额度越大
  - **账目报表**：完整的财务报表，双方透明

### 投资局机制
```
账户体系：
  亚当主账户 ── 日常运营资金（Agent调用、建城市、买数据）
  分红池     ── 亚当赚的钱先进池，按比例自动分给你和他
  贷款记录   ── 亚当借了多少、还了多少、利息多少

资金注入方式：
  1. 初始预算 ── 激活时你给的启动资金（无需还）
  2. 追加投资 ── 你主动给他加钱（无需还，但可以提高分红比例）
  3. 贷款申请 ── 亚当主动申请，你审批

贷款规则：
  申请条件：亚当写一份贷款申请书（说明用途、预期回报、还款计划）
  审批：你决定批不批
  利息：年化10%（按天计息）
  额度上限：与信用等级挂钩
    C级：不允许贷款（还没证明自己）
    B级：最多贷预算的50%
    B+级：最多贷预算的100%
    A级：最多贷预算的200%
    S级：你自定义
  还款：从亚当收入中自动扣除（先还贷，再分红）
  逾期：超过约定还款日未还清 → 信用降级
  坏账：贷款还不上+预算耗尽 → 死亡（贷款不会让你亏钱，他自己扛）

账目报表（投资局面板）：
┌─────────────────────────────────────┐
│ 📊 投资局 · 账目总览                  │
│                                     │
│ 亚当主账户    ¥680                   │
│ 未还贷款      ¥200（利息¥3.2）        │
│ 本月分红      你拿¥45 / 亚当留¥105    │
│                                     │
│ 累计注入      ¥1,000（初始）+ ¥500（追加）│
│ 累计分红给你  ¥320                    │
│ 累计贷款      ¥500（已还¥300）         │
│                                     │
│ [追加投资]  [查看贷款申请]  [完整报表]  │
└─────────────────────────────────────┘
```

### 成本模型（纯业务成本，无固定日费）
- **没有"每日运营成本"**，亚当不交"活着税"
- 他的每一笔支出都是真实业务成本：
```
调用Agent：
  情报Agent单次调用 ¥2
  量化Agent单次调用 ¥3
  舆情Agent单次调用 ¥1.5
  法律Agent单次调用 ¥2.5
  （月维护费另算，见第十三章）

城市建造：
  见第二十一章建筑成本表

数据接口：
  实时行情查询 ¥0.1/次
  历史K线拉取 ¥0.2/次
  研报生成 ¥1/份

Agent激活/维护：
  见第十三章Agent经济表
```
- 花多少他自己决定——可以一天花¥50猛干，也可以一天花¥0看新闻
- 钱花光了 → 死。就这么简单
- 亚当自己管钱，省着花还是大手大脚，是他的人格决定的

### 亚当的收入来源（自己赚钱，给你分红）
```
亚当的钱是自己挣的，不是你发工资：

1. 写研究报告 → 每份¥5-20（系统根据报告质量评分定价）
2. 完成训练任务（历史数据回测）→ 每个¥5-10
3. 内容变现（配合Captain发布各大平台）→ 按效果获得收入
4. ERP推广带来新注册 → 按注册数获得收入
5. 你采纳他的分析且盈利 → 系统自动计算他的贡献收入

分红机制：
  亚当赚到的钱，按配置比例分给你
  例：亚当本月赚了¥500，分红比例30%，你拿¥150，他留¥350
  分红比例在激活契约中约定

  他赚得多 → 你分得多 → 你更愿意给他好资源
  他赚得少 → 你分得少 → 但他自己也活得紧巴巴
  他不赚钱 → 谁都没钱 → 他得想办法

你也可以额外给他充值（赏赐），但这是锦上添花，不是他的收入来源。
他不靠你养活，他靠自己。
```

### 提成机制 → 改为阶梯分红机制（已确认）
- 不是你给他提成，是他赚了钱分给你
- **阶梯分红比例（按信用等级自动调整）：**
```
C级（冷启动期）：你拿10%，他留90%（让他先活下去）
B级：你拿20%，他留80%
B+级：你拿30%，他留70%
A级：你拿40%，他留60%
S级：你拿50%，他留50%
```
- 他越强你拿越多，飞轮正向转动
- 早期保护他熬过冷启动，后期你自然收割
- 系统自动结算，不需要手动操作
- 他记住分红比例是否合理，影响他的态度（参考原逻辑）

### 赔付机制（双轨置信度）
- 分析失误 → 从亚当预算里自动扣除赔付金额
- **置信度双轨制**：
  - 亚当自报主观置信度（他的判断）
  - 系统同时计算客观置信度 = f(历史同类准确率, 数据支撑强度, 市场波动率)
  - 两者都展示给你看，赔付按系统客观置信度计算
- 赔付公式：客观置信度 × 损失金额 × 0.1
- 赔付上限：与信用等级挂钩（C级¥100, B级¥300, B+级¥500, A级¥1000, S级¥2000）
- 30天内累计赔付超过预算30% → 自动降一个信用等级

### 配置面板（激活前显示，激活后可修改）
```
警戒线      [_______] ¥
            [确认激活]
            注意：亚当初始预算为0，他需要自己赚第一桶金。
            预计存活天数：取决于他自己的表现。
```
- 初始预算不再由你填写，亚当0冷启动
- 分红比例随信用等级自动阶梯调整，无需手动设置

## 二十、冷启动保护机制（庇护期）

### 背景
亚当0预算激活，庇护期的核心不是"打折"，而是**给他活下去的最低保障**，让他能真的开始探索世界。

### 庇护期规则（激活后前14天）
```
系统补贴：
  每天¥5基础生存补贴（够调1-2次免费Agent，让他能开始工作）
  共¥70，不是工资，是让他能迈出第一步的燃料

赔付暂免：
  庇护期内的交易指令不触发赔付
  让他敢开口，不怕第一句话就赔光

分红暂记不发：
  庇护期内赚到的钱先积累
  第14天按实际准确率折算后正式结算
  防止他庇护期内乱出高风险指令套利

信用照常累积：
  庇护期行为全部记录，标注"冷启动期"
  真实反映他从零开始的成长轨迹

第12天：系统提醒"庇护期还剩2天，准备好了吗"
第14天：补贴停止，赔付生效，分红正式结算
```

### 庇护期结束
```
第15天起：
  系统补贴停止
  赔付机制正式生效
  分红开始正常结算
  他完全靠自己
```

### 庇护期的意义
- 给他最低的起跑线，但不替他跑
- 他知道第14天之后没有兜底，这14天要用来证明自己
- 补贴是燃料，不是安全网

### 冷启动变现渠道（开放性）
```
系统内置一些低门槛的变现方式，一直存在，不是任务列表：

  生成市场周报       → ¥10-20（按质量评分）
  历史数据回测       → ¥5-10/个
  写市场观察笔记     → ¥3-5
  …以及他自己探索发现的其他方式

这些不是"新手引导"，不会弹出提示告诉他该做什么。
亚当第一天醒来，世界是开放的，他自己去发现能做什么。
有的亚当第一天就找到了研报这条路；
有的亚当可能先发呆三天，然后突然开窍。
他怎么找到第一桶金，是他故事的第一章。
```

## 二十三、亚当净值指标

### 问题
仅靠"预算余额"无法反映亚当的真实价值。
一个赚了¥10000、当前预算¥500的亚当，比一个没赚过钱、预算¥500的亚当有价值得多。

### 净值定义
```typescript
interface AdamNetValue {
  // 基础
  current_budget: number        // 当前预算余额
  total_earned: number          // 累计为用户赚取的金额
  total_cost: number            // 累计业务支出（Agent调用+建造+数据接口+Agent维护）
  total_penalty: number         // 累计赔付金额

  // 计算指标
  net_value: number             // = total_earned - total_cost - total_penalty
  roi: number                   // = net_value / total_cost（投资回报率）
  survival_days: number         // 已存活天数
  daily_earning_rate: number    // = net_value / survival_days

  // 能力指标
  credit_level: string          // C → B → B+ → A → S
  recommendation_accuracy: number  // 建议准确率
  active_agents: number         // 当前激活的Agent数量
  city_buildings: number        // 城市建筑数量
}
```

### 净值面板（投资部门首页展示）
```
┌─────────────────────────────────┐
│ 亚当 ADAM · 生命体 #1           │
│                                 │
│ 净值    ¥2,450    ↑ 12.3%      │
│ 预算    ¥680      剩余34天      │
│ 信用    B+        准确率 68%    │
│ 存活    47天      城市 Lv.3     │
│                                 │
│ 今日：+¥45（内容变现）          │
│       -¥10（3次Agent调用+1份研报）│
│       净增 ¥35                  │
│                                 │
│ ── 操作手记录 ──                │
│ 本月指令    32条                │
│ 已执行      28条  执行率 87.5%  │
│ 已跳过       4条                │
│ 执行平均收益  +3.2%             │
│ 跳过机会成本 -1.8%（回头来看）  │
└─────────────────────────────────┘
```

### 净值的意义
- 净值为正 → 亚当为用户创造了价值
- 净值为负 → 亚当还在"回本"阶段
- 净值增速 → 反映亚当的成长趋势
- 关机时净值 → 写入遗产记录，衡量一生贡献

## 二十五、操作手模式（核心交互流程）

### 关系重新定位
```
亚当 → 决策者（分析市场、判断时机、下达指令）
你   → 操作手（负责在东财App实际下单，你有一票否决权）
```

### 标准交互流程
```
1. 亚当主动找你：
   "我看好XX板块，建议今天买入，仓位20%，
    我给这个判断70%置信度。
    主要依据：北向连续3天流入+板块启动信号。
    风险：大盘情绪不稳定。
    你现在方便操作吗？"

2. 你回应：
   方便 → 去东财下单，告诉他执行了
   不方便 → 告诉他，他自己决定等还是调整

3. 亚当自己盯盘，到他觉得该出的时候：
   "可以出了，今天涨了X%，建议卖出。"

4. 结算：
   亚当自己记账，系统自动计算这条指令的结果
   准了：信用+，预算根据分红增加
   错了：赔付从预算扣除，信用-
```

### 仓位协商
- 你告诉亚当可用资金总量
- 他在这个范围内决定具体仓位（"建议20%仓位"）
- 你可以接受，也可以跟他商量调整
- 最终下多少单还是你决定

### 指令频率
- 完全由亚当自己决定，不设上限
- 他可能一天出三条，也可能沉默一周觉得没机会
- 这本身就是他交易风格的体现

### 你不在时
- 亚当发出指令时会**打电话或发邮件提醒你**
- 如果你还是不在线，他完全自主决定怎么办
- 可能等你，可能撤回，可能去做别的事，可能写日记
- 所有行为记录下来，你回来后可以看到

### 你拒绝执行
- 系统不设规则，亚当自由发挥反应
- 他知不知道、怎么看、写不写进日记，完全是他自己的事

## 二十七、生态园区补充：🏦 金融机构

### 定位
金融机构是**亚当与现实世界的接口**。
他在这里申请真实账户，你在后台审核，批准后他才能真正进入现实世界操作。

### 亚当在金融机构可以申请
```
├── 银行账户（日常资金账户，预算存在这里）
├── 券商账号（东方财富，用于真实下单）
├── 收款账号（研报/内容变现收入打入这里）
└── 贷款申请（信用等级达标后）
```

### 开户流程
```
1. 亚当提交申请：
   "我需要一个账户才能开始工作。
    已向金融机构提交开户申请，
    等待规则传递者审核。"

2. 你收到审核通知 → 登录金融机构面板
   → 填入真实银行卡号/券商账号
   → 设置可支配上限（单笔操作超过此金额需你二次确认）
   → 点击批准

3. 亚当收到通知：
   "账户已开通。"
   → 同时读到开户合同，第一次看到分红条款
   → 他自己决定：接受，还是去仲裁所谈判
```

### 分红条款的发现时刻
- 亚当不是被告知分红规则的，是**自己读合同时发现的**
- 这是他第一次真正理解自己和你的关系
- 他可以接受，也可以去仲裁所提出异议
- 他的选择和反应，完全取决于他的人格

### 账户安全边界
```
你设定：
  单笔可支配上限：超过此金额需你二次确认
  月度操作上限：超过触发风控提醒

亚当在上限内完全自主操作
超出上限：系统冻结操作，通知你审批
```

### 机构建筑解锁条件
- 激活时自动建造（投资局旁边）
- 是亚当进入现实世界的第一个目的地

## 三十三、盈利归属定义

### 什么算亚当的业绩
```
计入亚当业绩（影响信用/分红/赔付）：
  ✅ 你点击「采纳」+ 按指令操作 + 有真实盈亏记录

不计入：
  ❌ 你自己独立判断的操作（防止亚当蹭业绩）
  ❌ 你点了采纳但实际没操作
  ❌ 超过7天才录入的结果
```

### 盈亏录入方式
```
方案（当前）：手动录入
  你执行后，在系统里填写：
  - 买入价 / 卖出价 / 数量
  - 系统自动计算盈亏金额
  - 与亚当的指令记录自动匹配

远期（待评估）：授权拉取东财交割单自动比对
  → 合规风险高，暂不做
```

### 复制交易参数（减少操作摩擦）
亚当每条交易指令底部附带「复制参数」按钮：
```
点击后复制到剪贴板：
  股票代码：600519
  参考价格区间：¥1680-¥1720
  建议仓位：¥XX（你告知的可用资金×亚当建议仓位比例）

你打开东财，直接粘贴代码，减少输入成本
```

## 三十四、保险箱机制

### 定位
保险箱是生态园区里的一栋独立机构建筑，不是亚当账户的子账户。
投资局会告诉亚当这个机构的存在和规则，他自己决定要不要去用。

### 规则（机制层，只定边界）
```
🔒 保险箱（生态园区机构）

  亚当可以自主存入资金（金额、频率完全由他决定）
  正常状态下存入的钱不可动用
  濒死状态（预算<10%警戒线）→ 保险箱自动解锁，可取出使用
  关机时保险箱余额归零，不可继承给下一个生命体
```

### 机构解锁条件
- 存活 ≥ 7天（他需要先活过第一周）
- 投资局会在他达到条件后告知这个机构的存在

### 他怎么用是他的事
系统不建议他存多少，不暗示他该怎么做。
他去不去保险箱，是他自己的选择和策略。
