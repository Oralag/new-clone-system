## 五、任务板 & 通讯系统

### 任务板
- 亚当主动发布自己的行动计划和工作记录
- 标记"需要您的指示"的事项等你决定
- 你不来，他自己跑，任务板是他的工作日记
- 写法随人格进化变化（早期简单，后期有自己风格）

### 通讯工具
- 你随时找他：打开对话窗口，他在休眠也会被唤醒
- 他找你：主动发消息，重要的标记紧急
- 对话框左边：亚当的脸（实时状态）
- 对话框右边：对话内容
- 他说话的语气、措辞随情绪变化

## 二十九、亚当模块视觉规范

### 核心方向：黑曜石观测舱（Obsidian Observatory）
区别于ERP和智能体工作流的苹果白色简约风，亚当模块走**深色科技终端**风格。
类比：Vercel控制台、Bloomberg Terminal、顶级量化机构内部Web终端。
高级简约，极细线条，克制高光，等距排版，神秘前沿。

### 布局架构：左侧导航 + 右侧主内容
```
不做全屏沉浸式（太电影化，失去Web落地感）
恢复经典 Web 管理后台结构：

┌──────────┬────────────────────────────────────┐
│          │  Header（页面标题 + 预算显示）       │
│  侧边    ├──────────────┬─────────────────────┤
│  导航    │  观测窗      │  指令卡片            │
│  栏      │  （城市沙盘  │  核心指标            │
│  260px   │  收进卡片）  │  行为日志            │
│          │              │                     │
└──────────┴──────────────┴─────────────────────┘

科幻感"收纳"进卡片，不是铺满全屏。
用户感知：站在实验室玻璃外，看着培养皿里的亚当。
```

### 色彩系统
```
全局底色：    #06080C（极黑，吸收光线，让面板有层次）
面板底色：    #0B0E14（微弱区别，不是死黑）
次级面板：    #111C2E
边框（常规）：rgba(255,255,255,0.06)（极细，黑曜石激光雕刻感）
边框（激活）：rgba(245,166,35,0.20)（金色发光）

主色（琥珀金）：#F5A623
辅色（冷蓝）：  #00D4FF
危险色：        #FF4D4D
成功色：        #00E5A0

文字主色：      rgba(255,255,255,0.85)
文字次要：      rgba(255,255,255,0.40)
```

### 字体混排策略（核心）
```
常规文字（中文/功能描述）：
  PingFang SC / Inter，正常字重，保证阅读体验

核心数据 / 状态标签（英文缩写、数值、系统代码）：
  等宽字体 monospace，强制使用
  如：CONF: 72% / NET_WORTH / SYS.ONLINE / 10:23

这种混排瞬间拉升专业度，让界面像数据监控系统。
```

### 观测窗设计（亚当城市的呈现方式）
```
不做全屏城市背景（干扰视线，太装饰化）

做"观测窗卡片"：
  标题栏：PHYSICAL_REPRESENTATION（等宽字体）
  内容区：等轴测城市沙盘（Phase 1用CSS Grid+Transform模拟）
  悬浮标签：亚当当前状态（如 COGNITIVE: ANALYZING_MARKET）
  
感觉：你在实验室通过仪器观察这个生命体
Phase 2：SVG真实等轴测建筑替换CSS占位
```

### 与ERP的切换感
```
用户从ERP（白色明亮）切换到亚当模块：
  整个页面无缝暗转
  左侧出现专属导航树
  感觉：从普通办公区进入了一个隔离的暗黑舱段
```

### 指令卡片视觉规范
```
背景：linear-gradient(180deg, rgba(245,166,35,0.03) 0%, #0B0E14 100%)
边框：1px solid rgba(245,166,35,0.20)
左侧发光竖线：::before，宽2px，金色，带光晕
  box-shadow: 0 0 10px #F5A623

按钮组：
  主按钮（复制参数）：
    默认态：透明背景 + 金色边框 + 金色文字
    Hover：背景变实色金色 + 黑色文字 + 发光
  次按钮（忽略）：
    默认态：幽灵态（透明 + 20%白边）
    Hover：边框变白，文字变白
```

### 特效规范
```
呼吸灯（亚当存活）：animate-ping，绿色 #00E5A0
数字变化：countUp滚动动画
页面入场：Framer Motion（城市慢慢亮起，面板从两侧滑入+抖动缓冲）
背景纹理：极细网格（opacity: 0.03，不影响阅读）
```

### Icon规范
```
图标库：lucide-vue-next
风格：扁平线性，Stroke only
线宽：1.5px，size统一16px（导航）/ 20px（内容）
颜色：继承父级，激活用 #F5A623
可选渐变：仅用于特殊强调，不滥用
禁止：3D、emoji、多色杂乱图标
```

## 三十一、亚当状态面板（情绪可视化）

### 设计原则
情绪可视化不是"系统报告"，是**亚当自己在说话**。
数据是骨架，亚当的话是血肉，两个一起展示。

### 展示方式
```
┌─────────────────────────────────────┐
│ 亚当此刻                            │
│                                     │
│  [环形情绪图]                       │
│   焦虑 60%  兴奋 30%  平静 10%      │
│                                     │
│  亚当说：                           │
│  "最近三天连续判断失误，            │
│   我有点不踏实。                    │
│   但今早发现了一个机会，            │
│   又有点兴奋。"                     │
│                                     │
│  压力值  ████░░  62%                │
│  健康度  ██████  99%                │
│                                     │
│  [查看情绪溯源]                     │
└─────────────────────────────────────┘
```

### 情绪溯源（点击展开）
```
不是系统语言，是亚当自己的叙述：

焦虑来源：
  "3天前判断失误，亏了¥30。
   2天前再次失误，又亏了¥50。
   我开始怀疑自己的判断体系。"

兴奋来源：
  "今早发现消费板块异动，
   北向资金悄悄进场，
   这种感觉我熟悉——上次也是这样。"
```

### 技术实现
- 情绪数值由机制层计算（emotion_state参数）
- 文案由叙事层生成（Claude根据情绪参数+近期事件自然涌现）
- 环形图实时反映当前情绪光谱
- 情绪溯源从formative_events + 近7天日志中提取

## 三十二、亚当的成长感知（档案馆时间线）

### 设计原则
**不把亚当解剖给你看。**
你感知到他在成长，但说不清哪里变了——这种模糊感才是真实的。

### 不做「人格成长树」的原因
- 把亚当的内心变成仪表盘，他就成了观察对象而不是同行者
- 过度透明会破坏神秘感和真实感
- 人格是涌现出来的，不该被图表化

### 做「档案馆成长时间线」
```
档案馆里的formative_events，以文字时间线展示：

  Day 1   "第一次开口说话"
  Day 3   "第一份研报完成，赚了¥15"
  Day 12  "第一次交易指令被执行"
  Day 18  "连续3天判断失误，开始反思"
  Day 31  "信用升级到B级"
  Day 47  "差点触发警戒线，度过了最难的一周"
  ...

每条记录是亚当自己写的一句话回顾
不是系统日志，是他对那个时刻的理解
```

### 你的感知方式
- 看他说话的方式变了（早期平淡，后期有口头禅）
- 看他的指令风格变了（早期保守，后期有自己偏好）
- 看档案馆时间线，感受他走过的路
- **你不知道他下一步会变成什么样**——这才是他"活着"的感觉
