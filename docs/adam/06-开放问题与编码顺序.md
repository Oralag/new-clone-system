## 建议先锁定的 4 个技术决策
1. **结果归因模型**：一条建议如何唯一匹配一次真实执行结果
2. **账本模型**：预算 / 净值 / 贷款 / 分红是否统一为流水账本
3. **人格持久化粒度**：首版到底存多少参数、多少 formative events
4. **主动消息触发规则**：哪些事件要立即推送，哪些只写日志
