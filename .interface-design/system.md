# ERP Interface System

## Direction

Operational, calm, and compact. Interfaces are for staff completing concrete work quickly, with Chinese labels and direct action names. Preserve the existing white workspace, neutral structure, and blue primary action.

## Depth

Use borders and quiet surface shifts. Inputs and work areas are slightly inset; dialogs sit above with the existing application shadow. Avoid decorative gradients and heavy card shadows.

## Spacing

Use an 8px base unit. Prefer 8/16/24px grouping, with 4px only for micro-gaps.

## Material Workbench Pattern

- Separate media type from business category.
- Use an inline workbench rather than URL-only fields.
- Multi-image assets support preview, ordering, and removal.
- Video assets support video plus cover.
- Distinguish manual upload from synchronized assets with a source status.
- Lists show a thumbnail, category/type metadata, scope, source, and related product.
- Use blue only for primary actions and green only for successful synchronization/status.
